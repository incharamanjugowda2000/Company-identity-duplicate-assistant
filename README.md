# Company Identity & Duplicate Detection Assistant

A lightweight Sales Operations prototype that helps validate company identity and identify potential duplicate or related account records.

## What it does

- Checks company name and website consistency
- Identifies potential duplicate accounts
- Detects possible subsidiary relationships
- Flags country inconsistencies
- Highlights website/name similarity for further review
- Shows the existing account number and account name when a potential match is identified

## Who it's for

Sales Operations planning teams handling account creation and validation requests.

## Sample data

This prototype uses fictional/sample account data only. No real customer or confidential company data is included.

## What I'd build next

Connect the tool to a live account database so duplicate and hierarchy checks can be based on actual account records.
